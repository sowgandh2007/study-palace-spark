# StudySphere AI

## AI-Powered Collaborative Learning Platform

StudySphere AI helps students learn smarter through AI-powered roadmaps, real-time study rooms, and personalized learning assistance.

## Features

- AI-generated study roadmaps with topic-wise resources
- Interactive learning paths with progress tracking
- Multiplayer study rooms with:
  - Real-time collaboration
  - Shared goals and tasks
  - Chat
  - Polls
  - Study playlists
  - Resource sharing
- AI Tutor for explanations and doubts
- Learning analytics and mastery tracking

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Supabase
- AI APIs

## Problem

Students often struggle with consistency, finding the right resources, and creating effective study plans.

## Solution

StudySphere AI combines AI personalization with collaborative learning to create an engaging and adaptive study experience.

## Future Scope

- Voice AI tutor
- AI mock exams
- Mobile application
- Advanced adaptive learning
